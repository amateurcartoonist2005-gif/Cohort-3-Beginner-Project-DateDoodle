Frequently asked questions

What is DateDoodle?

DateDoodle is a calendar-based reminder tool. You mark your events, and it sends you fun, whimsical reminders matched to each event.

Can I only add 5 events? What if I want to add more?

You can have 5 events at a time. You can edit, delete or reschedule any event whenever you like, and more events can be added whenever a slot is available.

Is it free to use?

Yes, DateDoodle is free to use.
