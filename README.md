# Cohort-3-Beginner-Project-DateDoodle
A calender webpage to keep track of your important events and give you fun reminders so you never miss anything. Suitable for Genz who are used to social media's fun language and people with ADHD/Neuro-divergence who need their events reminded frequently and in a fun way.
This was made as beginner web developing project for a 24 day training session in which we learned basics of web development and how to use AI tools, such as Claude, to generate simple codes for us.
